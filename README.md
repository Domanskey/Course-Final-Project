# Course-Final-Project

Final project for the "WTF: Co Ten Frontend" course. The goal was to build a responsive, accessible, and optimized website based on a Figma design using GitHub API. Developed using React, Tailwind CSS, and JavaScript.

## Goals of this project are:

- Using Github API
- Implementing Figma Designs
- Website Optimization For Different Devices

## How to run?

- npm install
- npm run dev
